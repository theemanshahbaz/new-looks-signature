# ✨ New Looks Signature by Sadia Parlor 
### A Premium Beauty Salon Landing Page

This is a professional, high-end landing page designed for a beauty salon. It features a modern dark-themed aesthetic with gold accents, fully responsive design, and an integrated booking management system.


---

💎 Features

*   **Premium UI/UX:** Built with a "luxury feel" using Playfair Display and Poppins typography.
*   **Fully Responsive:** Optimized for mobile, tablet, and desktop views.
*   **Booking System:** Integrated contact form with date/time picker.
*   **Admin Dashboard:** A hidden administrative panel for viewing and managing bookings (Demo Login included).
*   **Interactive Components:** 
    *   Sticky Navigation with active states.
    *   Dynamic Modals for Admin login and dashboard.
    *   Google Maps Integration for location tracking.
*   **Modern Tech Stack:** Built using Tailwind CSS for rapid, modern styling.

---

 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (Custom animations)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Fonts:** Google Fonts (Playfair Display & Poppins)
*   **Icons/Images:** Unsplash API & FontAwesome
*   **Interactive Components:** Flatpickr (Date/Time Picker)
